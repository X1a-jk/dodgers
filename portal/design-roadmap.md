# 道奇数据门户扩展设计（头脑风暴存档）

> 创建时间：2026-08-21
> 用途：记录门户未来可扩展的模块与功能，供后续逐个实现参考

---

## 设计愿景

将当前的三个模块（球员报告、每周战报、每日阵容）升级为 **"道奇队数字作战室"（Dodgers Digital War Room）**：
一个集数据可视化、赛程追踪、伤病监控、阵容管理与球迷互动于一体的综合门户。

---

## 第一阶段：马上就能做（基于现有数据）

### 1. 数据可视化大屏（Stats Dashboard）
- **实时战绩条**：胜/负、胜率、分区排名、外卡/季后赛概率
- **本周打线状态卡**：最近 7 天 OPS Top 5 + Bottom 3
- **先发轮值看板**：接下来 5 场先发、ERA、WHIP、上次表现
- **牛棚温度计**：最近 7 天 ERA、inherited runners 得分率、高杠杆成功率
- **红榜/黑榜速览**：从周报自动抽取，无需点开 Markdown

### 2. 赛程与比赛中心（Schedule & Game Hub）
- 日历视图：本月所有比赛，胜/负/待赛颜色区分
- 下一场比赛倒计时 + 先发对决
- 上一场快速复盘：比分、关键球员、决胜时刻
- 系列赛总结：当前系列赛战绩、历史对战记录

### 3. 伤病追踪时间线（Injury Timeline）
- 所有 IL 球员横向时间轴：入 IL 日期、预计回归、状态更新
- 伤兵营 vs 活跃名单人数对比
- 关键球员回归倒计时

### 4. 40 人名单深度图（Depth Chart）
- 按位置排列：捕手 → 内野 → 外野 → 先发 → 牛棚
- 每个位置主力 + 替补 + 小联盟备选
- 点击球员直接跳转球员报告

### 5. 文件版本时间轴（Portal Activity Feed）
- GitHub 风格贡献墙：哪天有新日报、周报、球员报告更新
- 最近 30 天内容产出热度图

## 第二阶段：进阶扩展（需要额外数据抓取）

### 6. 农场系统与小联盟（Farm System）
- 道奇 Top 30 新秀列表 + 当前层级
- 小联盟每日亮点：谁今天双响、完投、盗垒
- 新秀升级预警：AAA 表现突出、可能被上调的球员

### 7. 交易与人员变动（Transaction Tracker）
- 40 人名单变更流水：DFA、交易、IL 回归
- 模拟阵容工具：调整名单后自动显示新阵容

### 8. 对手情报局（Opponent Scout）
- 下一场对手近期战绩、王牌投手、关键打者
- 对战历史：道奇 vs 对手最近 10 场
- 球场因子：Coors Field 等球场对打线影响

### 9. 里程碑与纪录（Milestones）
- Ohtani 离下一支全垒打还差几支
- Mookie Betts 生涯 WAR 排名
- 道奇队史同期对比：2026 vs 2024 冠军年

### 10. 季后赛模拟器（Postseason Simulator）
- 若赛季今天结束，道奇首轮打谁
- 剩余赛程难度排名
- 夺冠概率预测（可接 FiveThirtyEight / Baseball Prospectus）

## 第三阶段：互动与体验增强

### 11. 球员对比工具（Player Comparison）
- 选两名球员并排对比：生涯数据、当年数据、防守指标
- 示例：Mookie vs Freddie Freeman，Blake Snell vs Yamamoto

### 12. "我的道奇"收藏面板（My Dodgers）
- 收藏最爱球员，首页显示其最新动态
- 关注名单：指定球员上场、进入 IL 时高亮提醒

### 13. 预测小游戏（Fan Predictions）
- 预测明天比分、Ohtani 是否轰、系列赛结果
- 赛季末自动计算预测准确率

### 14. 主题与氛围（Themes）
- 普通模式 / 赛日模式（赢球蓝 / 输球暗红）
- 季后赛模式：十月专属皮肤

### 15. PWA 化 / 手机友好
- 保存到手机桌面像 APP
- 推送通知：比赛开始、关注球员上场

### 16. 快速搜索 / 命令面板（Command Palette）
- 按 `/` 或 `Ctrl+K` 弹出搜索
- 搜球员、搜日期、搜比赛、跳模块

### 17. AI 聊天小助手
- 右下角悬浮机器人
- 回答 "昨天谁表现最好？""道奇先发轮值怎么排？" 等问题

### 18. 内容订阅
- 邮件 / 企业微信 / 飞书机器人：日报/周报自动生成后自动推送摘要

## 第四阶段：视觉与氛围

### 19. 实时比分条（Live Score Ticker）
- 顶部滚动显示：今天道奇比分、其他关键场次比分

### 20. 球员生日与纪念日
- 今天是谁生日？道奇队史今天发生过什么？

### 21. 比赛日倒计时小部件
- 首页显示："距离下一场道奇比赛还有 XX 小时 XX 分钟"

### 22. 社媒与新闻聚合
- 拉取 MLB.com、Dodgers Nation、The Athletic 道奇新闻标题
- Dodgers 官方 Twitter/X 最新动态

## 推荐优先实现的 4 个模块

如果想先搞最容易出彩的：

1. **数据可视化大屏**：一打开门户就看到球队整体状态
2. **40 人名单深度图**：把日报名单数据可视化，点人进球员报告
3. **下场比赛卡片**：倒计时 + 先发对决，放首页最显眼位置
4. **伤病时间线**：名单管理是痛点，一眼看清谁快回来了

这些基本都能用现有 MLB API 数据和周报/日报数据实现，不需要额外数据源。

---

## 实现建议

- 每个新模块先做一个独立 HTML 或 JS 组件，再集成进 `index.html`
- 优先复用现有数据：MLB Stats API、`weekly/`、`roster/`、`report/index.html`
- 需要新数据的模块，先写 Python 脚本抓数据并落盘到 `D:\baseball\data\`
- 保持 Dodgers 蓝 (#005A9C) 主题，深色背景，卡片化设计
